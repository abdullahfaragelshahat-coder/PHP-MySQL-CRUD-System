# 📦 نظام إدارة المستودع والمنتجات (CRUD System)

مشروع متكامل لإدارة المنتجات والمخازن مبني باستخدام لغة **PHP Native** وقواعد بيانات **MySQL** بشكل آمن واحترافي.

## ✨ الميزات البرمجية في المشروع:
* **CRUD Operations:** إضافة، قراءة، تعديل، وحذف المنتجات بسلاسة.
* **Security (PDO):** استخدام الـ Prepared Statements لحماية الموقع تماماً من ثغرات SQL Injection.
* **Validation:** فحص صارم للمدخلات لضمان عدم إدخال بيانات فارغة أو أسعار سالبة.
* **Image Upload:** رفع صور المنتجات وتوليد أسماء فريدة لها باستخدام الوقت لمنع تداخل الملفات، مع فحص الحجم والصيغة.
* **Search System:** محرك بحث مرن يعتمد على أمر `LIKE` للبحث بالاسم أو السعر.
* **Pagination:** تصفيف ديناميكي يعرض 3 منتجات فقط في الصفحة للحفاظ على سرعة وأداء الموقع.

## 🛠️ التقنيات المستخدمة:
* HTML5 / CSS3
* PHP (PDO)
* MySQL Database
